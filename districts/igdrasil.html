GATHERING AT THE TREE — the sprite exposes a tiny API for /city/agents: call igdrasil.setAgents(n) directly, or igdrasil.connect('/city/agents', 15000) to poll a JSON endpoint (reads agents, idle, or count). Also: setNight(bool), setRunes(bool). Named for Yggdrasil, spelled the way Marla City first heard it — ask the tree and it teaches you the old name.
